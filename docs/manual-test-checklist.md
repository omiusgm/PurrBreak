# PurrBreak Manual Test Checklist

Короткий чеклист перед публичным релизом. Его цель - поймать реальные UX-поломки, а не заменить автоматические тесты.

## Установка и первый запуск

- Скачать актуальный `PurrBreak-*-macOS.zip` из GitHub Releases.
- Распаковать архив.
- Перетащить `PurrBreak.app` в `/Applications`.
- Запустить через right click -> `Open`, если macOS показывает предупреждение.
- Убедиться, что при первом запуске открывается окно доступа к браузерам.
- Убедиться, что при последующих запусках приложение стартует тихо в меню-баре.

## Браузеры

- Safari: открыть `youtube.com`, разрешить Automation, проверить что статус стал подключен.
- Google Chrome: открыть `youtube.com`, разрешить Automation, проверить что счетчик идет.
- Yandex Browser: открыть `youtube.com`, проверить что счетчик идет.
- Браузер без YouTube: открыть обычный сайт, проверить что счетчик не идет.
- Firefox: проверить что он отображается как пока не поддержанный текущим AppleScript-механизмом.

## YouTube и Shorts

- Обычный YouTube: проверить основной лимит.
- `youtube.com/shorts`: проверить отдельный короткий лимит.
- `youtu.be/...`: проверить что считается как обычный YouTube.
- Сбросить счетчик из главного окна и из меню-бара.

## Пауза и тест заставки

- На чистом профиле или после сброса настроек проверить, что длина паузы по умолчанию 3 минуты.
- Нажать `Тест заставки`.
- Проверить, что клики проходят сквозь тестовый overlay.
- Закрыть тест через `Esc`.
- Запустить `Блокировка сейчас`.
- Проверить, что настоящая пауза перекрывает все подключенные экраны.
- Проверить, что во время паузы виден текст про отдых и заблокированные клавиатуру/мышку.
- Проверить, что активное YouTube-видео ставится на паузу при запуске настоящей паузы.
- Дождаться конца паузы и проверить окно выбора следующего шага.

## Настройки

- Сменить язык RU/EN.
- Сменить заставку.
- Сменить формат меню-бара: `Purr 15:08`, `15:08`, `15м`, варианты с иконкой.
- Изменить лимит YouTube, лимит Shorts и длину паузы.
- Включить/выключить мурчание и громкость.
- Включить `Запускать при входе в macOS`, проверить статус в Login Items.
- Нажать `Отправить отзыв` в справке и проверить, что открывается GitHub Issue.

## Companion extension

- Скачать актуальный `PurrBreak-Companion-*.zip` из GitHub Releases.
- Распаковать и установить как unpacked extension в Chromium-браузере.
- Проверить `Hide Shorts`.
- Проверить `Hide homepage`.
- Проверить `Hide sidebar / recommendations`.
- Проверить `Disable autoplay`.
- Проверить экспериментальные Instagram/Reels toggles.

## GitHub Pages и README

- README показывает иконку и два product mockup-скрина.
- Latest release содержит `PurrBreak-*-macOS.zip` и `PurrBreak-Companion-*.zip`.
- Если GitHub Pages включен: проверить `https://omiusgm.github.io/PurrBreak/`.
- Если Pages дает `404`: включить Settings -> Pages -> Build and deployment -> GitHub Actions и перезапустить workflow `Pages`.
